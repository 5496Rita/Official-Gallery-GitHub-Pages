Official Gallery v4.0

実装内容
- Exhibitionの不規則配置・大小・傾き・奥行き
- ジャケットクリックで右側からARCHIVE DETAILを表示
- 収蔵番号、作品区分、Story、Track List、XFD、配信リンク
- Previous / Nextによる作品巡回
- URLハッシュによる作品詳細への直接リンク
- スマホ表示対応

公開手順
1. このフォルダの中身をGitHub Desktopで管理しているフォルダへ上書き
2. GitHub DesktopでSummaryに Official Gallery v4.0 と入力
3. Commit to main
4. Push origin
5. GitHub ActionsがSuccessになったら公開ページをCtrl+F5
