Official Gallery Update Guide

1. ZIPを展開します。
2. 中にあるファイルとフォルダを、GitHub Desktopで管理しているリポジトリ直下へすべて上書きします。
3. GitHub Desktopで変更内容を確認します。
4. Commit to main を押します。
5. Push origin を押します。
6. 公開ページを再読み込みします。古い表示が残る場合は、ブラウザのキャッシュを無視して再読み込みしてください。
